# Desafio QA 

Automação de testes do [demoqa.com](https://demoqa.com) com Cypress, Cucumber e Page Objects.

O projeto está na pasta `cypress-desafio/`. Para rodar:

```
cd cypress-desafio
npm install
npm test
```

O que está coberto:

- API: criar usuário, gerar token, confirmar autorização, listar e alugar livros e conferir os dados do usuário.
- Web: Practice Form, Browser Windows, Web Tables (com o bônus dos 12 registros), Progress Bar e Sortable.

Mais detalhes, incluindo os bugs do demoqa que encontrei, estão no README da pasta `cypress-desafio`.
